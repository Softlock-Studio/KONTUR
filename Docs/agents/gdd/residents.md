# Residents

- Regular residents continue living in the building.
- They generate **random events**: help requests, emergencies, additional tasks
  for the team.
- Resident events are handled via the "working with residents" employee task type
  (see [employees.md](employees.md)).
- Residents can be in various infection states — see [lore-spore-syndrome.md](lore-spore-syndrome.md)
  for symptom/state details.
