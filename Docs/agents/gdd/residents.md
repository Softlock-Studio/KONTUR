# Residents

- Ordinary residents continue to live in the building during operations
- Random events: requests for help, emergencies, additional tasks for the team

## Event types (general categories)
- Requests for help
- Emergency situations
- Additional tasks for staff

## Spore syndrome signs (for detecting infected residents)
- Craving to gnaw chalk/concrete (exophthalmos)
- Apathy/forgetfulness
- Strange attraction to smooth concrete
- "Mooing"/vocalization with spore release
- Sharp weight loss
- Unnatural smile
- Thinning of limbs

## Resident infection states
- Passive / Active (same as entities)
- "Anxiety" state: infected realized they are being observed → targeted aggression toward the witness

## Goncharov Test
- Place chalk pieces in a room → infected resident compulsively eats it
- Diagnostic tool for identifying infected residents

## Mutation threshold
- Behavioral changes begin at 100 spores/μL (test "Lunch")
