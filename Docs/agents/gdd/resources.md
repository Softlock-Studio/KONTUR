# Resources

Storage: single counter per resource type (shared pool; not physically carried by staff). Displayed on screen.
Resources do not spawn randomly (tentative).

| Resource | Properties |
|----------|-----------|
| Vinegar (9%) | Cheap, frequent; weak single-use effect; creates acidic environment in concrete pores, slows infection |
| Iodine-Resorcinol-A | Rare; strong long-lasting effect; reduces infection to minimum long-term; additionally repels the grandmother (smell aversion); sharp "metro smell" |
| KONTUR agent | Slows infection growth in room long-term (lore: –89%); contains iodine-resorcinol-A |
| Carpets | Preventive measure; weaker than KONTUR agent; cheaper; must be re-laid each night; 3–6 pieces per room per lore; lore: prevents appearance of Vestnik entity; spray with vinegar several times per week |
| Light bulbs | Consumable for "replace bulb" task; removes Darkness factor from a room; improves camera visibility |
| Generator fuel | Shared tank per night; powers ASS/cameras/lighting and full house scan; at 0 generator shuts off |
