# Camera System

- Switch between cameras placed around the building.
- ACS (Autonomous Surveillance System) cameras have motion sensors and autonomous
  power; can perform Object stabilization function instead of a human (see
  [lore-stabilization.md](lore-stabilization.md)).
- Without activity ACS records at reduced frame rate (battery conservation).

## What cameras enable
- Track **employees** (visual).
- Monitor **grandmother** position (visual).
- Find new tasks (dirty zone, broken camera, etc.).
- Detect new threats — e.g., visual markers like **Vestnik** (indicator of an
  unnoticed infection outbreak visible in frame).
