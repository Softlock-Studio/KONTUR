# Floor Map (Mini-map)

- Separate screen with floor plan
- Displays:
  - Staff positions (via GPS — always current)
  - Camera locations
  - Grandmother position (if known)
  - Infection hotspots
  - Quick-time events (if implemented)
- Selected room is highlighted
- Clicking a squad group on the map → context menu for assigning tasks
- **Fog of war:** map shows only what the player last observed; data becomes stale if a camera has not been checked recently (relevant for moving entities such as the grandmother)
