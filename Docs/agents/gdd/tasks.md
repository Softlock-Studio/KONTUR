# GDD extract: Employees & tasks

## Assignment UX
- The player never controls employees directly.
- Flow: **click employee → click room → context menu** with the actions
  available there. Clicking a group on the floor map opens the same menu.
- The player interacts with **one employee at a time**.

## Task types
| Task | Effect | Timing |
|---|---|---|
| Treat zone | apply vinegar / iodine-resorcinol → lowers zone infection | 30–60 game min |
| Scout room | recon: reveals new hotbeds / threats | TBD |
| Change light bulb | adds light: slower infection growth, better camera view | TBD |
| Fix camera | reactivates a dead camera | TBD |
| Resident work | react to resident events / requests | TBD |
| Babooshka actions | e.g. lure her, leave her food | TBD |

## Residents
Ordinary residents stay in the house during operations. They produce random
events: requests for help, emergencies, extra tasks for the team.
(Infected residents and mimics: see entities.md.)

## Threats to employees
- Babooshka kills an employee on contact — see babooshka.md.
- Future entities each have a diegetic trigger rule — see entities.md.
- Employees wear gas masks (spores are stopped by filters).
