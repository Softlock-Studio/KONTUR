# Night System

## Structure
- Game divided into night shifts with a timer
- Starting night duration: ~7 real minutes per game night

## Night-to-night progression
- Each new night increases overall infection level
- Several nights form a cycle — player must maintain infection level across the full cycle
- Must finish each night of the cycle within the acceptable infection corridor

## Infection corridor
- Goal is not "keep infection below ceiling" but to maintain it in corridor [floor; ceiling]
- The corridor shifts upward from night to night

## General systems
- Full house infection scan via single button (taps generator fuel)
- Generator: shared fuel resource that powers cameras, ASS, lighting, and full scan; shuts off at 0
