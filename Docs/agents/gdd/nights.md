# Night System

- Gameplay divided into **night shifts**.
- Timer per shift.
- **Starting night length: ~7 real minutes** per in-game night.

## Escalation
- Each new night increases baseline infection.
- Several nights form a **cycle** — player must maintain infection in the corridor
  across the whole cycle.
- Must end each shift of the cycle within the acceptable infection corridor
  (see [game-loop.md](game-loop.md)).
