# Employee Management

## Interaction model
- Player assigns tasks via UI; does **not** directly control employees.
- UI flow: click employee → click room → context menu with available actions.
- Player interacts with **only 1 employee at a time**.

## Task types
- Treatment of infected zone.
- Room investigation (scouting, detecting new outbreaks/threats).
- Working with residents (responding to events/requests).
