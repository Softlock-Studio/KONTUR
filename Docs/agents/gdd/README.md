# GDD Extracts — House Rules

These files are a **cache** of the live GDD (Russian, maintained by the game designer).
The Google Doc is the source of truth; extracts must be refreshed when the doc changes.

## Extraction rules
- English only.
- Facts and design constraints only — no interpretation, no filler.
- Blank or unspecified numbers → **TBD**; never invent values.
- Each file covers one design area, kept under ~150 lines.
- A genuinely new design area gets a new file + a row in the table below.
