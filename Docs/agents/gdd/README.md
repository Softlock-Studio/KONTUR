# GDD Extracts — Rules

These are machine-readable summaries of the KONTUR GDD.
Source of truth: the live Google Doc (Russian, maintained by the game designer).
Refreshed by the `gdd-sync` agent; do not hand-edit unless correcting a sync error.

## Rules

- **English only.** Translate facts; omit Russian prose.
- **Facts and constraints only.** No rationale, aesthetic intent, or wishful thinking.
- **TBD** for any numeric value left blank in the doc. Never invent values.
- **~150 lines max per file.** Split into a new file if a topic grows larger.
- **One topic per file.** A genuinely new design area gets a new file + a new row in this table.
- Images stripped. The doc export has none; do not embed any.
